# 🇬🇧 English Mastery

> Aprende inglés desde los fundamentos hasta un nivel avanzado, entendiendo cómo funciona el idioma y utilizándolo en situaciones reales.

---

## 🎯 Objetivo

**English Mastery** es una ruta de aprendizaje para estudiar inglés desde **A0 hasta C1**.

El objetivo no es solo memorizar reglas, sino aprender a:

* 🧠 Entender cómo funciona el inglés.
* 📖 Leer y comprender contenido en inglés.
* 🎧 Entender conversaciones.
* 🗣️ Hablar con mayor seguridad y naturalidad.
* ✍️ Escribir correctamente.
* 💼 Utilizar inglés en situaciones personales y profesionales.

---

## 🧩 Los 8 pilares

El aprendizaje se divide en ocho áreas:

| Área                       | ¿Qué aprenderemos?                               |
| -------------------------- | ------------------------------------------------ |
| 🧩 **Grammar**             | Cómo construir correctamente frases y preguntas. |
| 📚 **Vocabulary**          | Palabras y expresiones para comunicarnos.        |
| 🔊 **Pronunciation**       | Cómo pronunciar correctamente el inglés.         |
| 🎧 **Listening**           | Cómo entender inglés hablado.                    |
| 🗣️ **Speaking**           | Cómo expresar nuestras ideas hablando.           |
| 📖 **Reading**             | Cómo comprender textos en inglés.                |
| ✍️ **Writing**             | Cómo escribir de forma correcta y natural.       |
| 🧠 **Thinking in English** | Cómo reducir poco a poco la traducción mental.   |

## 🏗️ Primero los fundamentos

Antes de estudiar estructuras más complejas necesitamos entender las piezas básicas del idioma.

```text
Foundations
    ↓
Pronouns
    ↓
Verb To Be
    ↓
Simple Present
    ↓
Present Continuous
    ↓
...
```

Por ejemplo, antes de aprender:

> **She works every day.**

debemos entender qué es:

```text
She     → Subject / Pronoun
works   → Verb
every day → Time expression
```

La idea es **entender la regla antes de memorizarla**.

## 🔄 Cómo aprenderemos

Cada concepto seguirá un ciclo sencillo:

```text
Entender
   ↓
Ver ejemplos
   ↓
Practicar
   ↓
Leer
   ↓
Escuchar
   ↓
Escribir
   ↓
Hablar
   ↓
Repetir
```

La repetición es parte del aprendizaje.

No buscamos simplemente:

> ❌ "Ya estudié Simple Present."

Buscamos llegar a:

> ✅ "Entiendo Simple Present y puedo utilizarlo."

## 🌱 Filosofía

> **Understand first. Practice often. Use English every day.**

No se trata de aprender inglés rápido.

Se trata de construir una base suficientemente sólida para poder **leerlo, escucharlo, escribirlo y hablarlo cada vez con mayor naturalidad**.
